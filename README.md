# InternNova Task 6 – Data Analytics & Power BI Project

## 📌 Overview
This repository contains all tasks completed during **InternNova Week 6**.  
The project demonstrates end-to-end data analytics workflow — from Git basics and dataset preparation to exploratory analysis, visualization, and interactive dashboards in Power BI.

---

## 🗂️ Tasks Completed

### **Task 1 – Git & GitHub Basics**
- Created a GitHub repository: `Week6-DataAnalytics-InternNova`.
- Initialized with README, LICENSE, and `.gitignore`.
- Practiced Git commands: `git init`, `git add`, `git commit`, `git push`, `git pull`.
- Outcome: Repository successfully set up with version control.

---

### **Task 2 – Git Workflow Practice**
- Cloned repository locally using `git clone`.
- Added files and committed changes (`git commit -m "RetailDataset"`).
- Pushed updates to GitHub and pulled latest changes.
- Outcome: Hands-on practice of Git workflow ensuring smooth collaboration.

---

### **Task 3 – Dataset Selection & Preparation**
- Selected **RetailDataset.xlsx** with 100 records.
- Inspected dataset using Python (Pandas): `.head()`, `.info()`, `.describe()`.
- Verified data types, checked for missing values and duplicates.
- Cleaned dataset and saved as `cleaned_dataset.csv`.
- Outcome: Clean dataset ready for analysis.

---

### **Task 4 – Exploratory Data Analysis (EDA)**
- Performed statistical analysis (mean, median, mode, variance, std. deviation).
- Outlier detection using IQR method.
- Correlation analysis:
  - Sales ↔ Profit: Strong positive correlation (0.82).
  - Discount ↔ Profit: Negative correlation (-0.10).
  - Quantity ↔ Sales: Moderate correlation (0.31).
- Outcome: Key insights into dataset relationships identified.

---

### **Task 5 – Data Visualization**
- Created visualizations using **Matplotlib & Seaborn**:
  - Line Chart: Sales trend by OrderID.
  - Bar Chart: Profit by Category.
  - Pie Chart: Sales share by Region.
  - Histogram: Sales distribution.
  - Scatter Plot: Sales vs Profit.
  - Heatmap: Correlation matrix.
- Outcome: Clear visual representation of dataset patterns.

---

### **Task 6 – Power BI Dashboard**
- Imported dataset into Power BI.
- Created visuals:
  - Clustered Column Chart: Sales by Region.
  - Pie Chart: Profit by Category.
  - Line Chart: Discount % trend.
  - Table/Matrix: Order details.
- Added KPI Cards: Total Sales, Average Profit, Profit Margin.
- Inserted slicers for Region and Category to enable interactivity.
- Outcome: Professional interactive dashboard built for dynamic analysis.

---

## 📊 Tools & Technologies Used
- **Git & GitHub** – Version control and collaboration.
- **Python (Pandas, NumPy, Matplotlib, Seaborn)** – Data cleaning, EDA, visualization.
- **Excel** – Statistical calculations and validation.
- **Power BI** – Dashboard creation and interactive analysis.

---

## 🚀 Conclusion
This project demonstrates the complete data analytics pipeline:
1. Version control with Git/GitHub.  
2. Dataset preparation and cleaning.  
3. Exploratory analysis and statistical insights.  
4. Visualization in Python and Seaborn.  
5. Interactive dashboards in Power BI.  

The final outcome is a **business-ready dashboard** that highlights sales, profit, and discount trends, enabling clear decision-making.
